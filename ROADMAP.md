CPE Simulator — Development Roadmap

Project Vision

Build an open-source electrical and industrial control simulator for learning, circuit design, simulation, and engineering analysis.

Development Principles

- Web, Mobile, and Desktop support.
- Arabic and English from the first release.
- Local project storage with optional cloud synchronization.
- Partial offline support for core simulation features.
- Modular architecture to support community contributions.

Phase 1 — Foundation

- Define project architecture.
- Establish development guidelines.
- Select the initial technology stack.
- Create the project structure.
- Document safety and simulation limitations.

Phase 2 — Classic Control MVP

- Circuit editor.
- Electrical components library.
- Wires and connections.
- DOL motor starter.
- Start/Stop control.
- Contactor auxiliary contacts.
- Overload protection.
- Self-holding logic.
- Basic fault simulation.

Phase 3 — Simulation Expansion

- Forward/Reverse.
- Star-Delta.
- Timers and relays.
- Electrical interlocks.
- ATS control circuits.

Phase 4 — PLC and Industrial Automation

- Ladder Logic editor.
- PLC simulation engine.
- Timers and counters.
- Sensors and actuators.
- VFD control.
- Industrial automation scenarios.

Phase 5 — Electrical Power

- Load calculations.
- Cable sizing.
- Voltage drop calculations.
- Protection device selection.
- Short-circuit analysis.
- Three-phase system analysis.

Phase 6 — Cross-Platform and Collaboration

- Web application.
- Mobile experience.
- Desktop application.
- Local project storage.
- Optional cloud synchronization.
- Partial offline operation.
- Arabic and English interfaces.

Phase 7 — Community and Growth

- Documentation and tutorials.
- Community contributions.
- Testing and validation.
- Additional simulation modules.

Current Status

Planning and foundation stage. The first implementation target is the Classic Control MVP.

This roadmap is subject to change as the project develops.
