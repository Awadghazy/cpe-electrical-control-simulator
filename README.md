English

About

CPE Simulator is a free and open-source project designed to simulate electrical circuits, classic control systems, PLCs, and industrial automation.

Our goal is to provide an accessible platform for students, technicians, engineers, and developers to learn, design, test, and simulate electrical control systems.

Main Features

- Classic Electrical Control
- Electrical Power Systems
- Relay and Contactor Simulation
- Motor Control
- PLC and Ladder Logic
- Industrial Automation
- VFD Simulation
- ATS Simulation
- Interactive Learning Environment
- Engineering Analysis Tools
- Circuit Design and Testing
- Fault Detection and Simulation

Supported Platforms

CPE Simulator aims to support three platforms:

1. Web

- Runs directly in modern web browsers.
- No installation required.

2. Mobile

- Android and iOS support.
- Responsive interface for mobile screens.
- Touch-friendly circuit editor.
- Drag and drop components.
- Touch-based wire connections.
- Pinch-to-zoom support.
- Progressive Web App (PWA) installation.

3. Desktop

- Windows support.
- Other desktop operating systems as development progresses.
- Desktop application powered by Tauri.

Project Status

Currently in the foundation and planning stage.

The initial development target is a Classic Control simulator.

The first release will focus on building, connecting, and simulating basic electrical control circuits.

Technologies

- React
- TypeScript
- SVG
- Tauri (Desktop)
- Progressive Web App (PWA)
- Responsive UI (Mobile and Web)
- Git
- GitHub

Architecture

CPE Simulator aims to use a shared simulation engine across all supported platforms.

The project will be developed using a modular architecture to allow developers to contribute independently to different components.

Planned modules include:

- Circuit Editor
- Component Library
- Simulation Core
- Electrical Analysis Tools
- PLC Engine
- Project Manager

Learning and Engineering Modes

Learning Mode

Designed for students and technicians.

- Interactive tutorials.
- Component explanations.
- Practical electrical exercises.
- Circuit behavior visualization.
- Fault simulation and troubleshooting.

Engineering Mode

Designed for engineers and experienced technicians.

- Circuit design.
- Electrical simulation.
- System analysis.
- Fault testing.
- Engineering calculations.
- Technical reports.

Engineering results will include documented assumptions and limitations and will not replace certified engineering verification.

Open Source

CPE Simulator is developed as a community-driven open-source project under the GNU AGPL-3.0 license.

Contributions from developers, electrical engineers, technicians, educators, and students are welcome.

We believe that electrical simulation and technical education should be accessible to everyone.

Long-Term Vision

Our long-term goal is to build a comprehensive platform for:

- Classic Control
- Electrical Power Systems
- PLC Programming
- Industrial Automation
- Motor and Drive Systems
- Electrical Protection
- Engineering Analysis

العربية

عن المشروع

محاكي CPE هو مشروع مجاني ومفتوح المصدر يهدف إلى محاكاة الدوائر الكهربائية وأنظمة التحكم التقليدي (Classic Control) ووحدات التحكم المنطقية المبرمجة (PLC) والأتمتة الصناعية.

نسعى إلى توفير منصة متاحة للطلاب والفنيين والمهندسين والمطورين للتعلم والتصميم والاختبار ومحاكاة أنظمة التحكم الكهربائية.

المميزات المستهدفة

- محاكاة دوائر Classic Control
- أنظمة القدرة الكهربائية
- محاكاة الريليهات والكونتاكتورات
- التحكم في المحركات
- PLC وLadder Logic
- الأتمتة الصناعية
- محاكاة VFD
- محاكاة ATS
- بيئة تعليمية تفاعلية
- أدوات التحليل الهندسي
- تصميم واختبار الدوائر
- اكتشاف الأعطال ومحاكاتها

المنصات المدعومة

يهدف CPE Simulator إلى العمل على ثلاث منصات رئيسية:

1. الويب (Web)

- يعمل مباشرة من متصفحات الإنترنت الحديثة.
- لا يحتاج إلى تثبيت.

2. الهواتف (Mobile)

- دعم Android وiOS.
- واجهة متجاوبة مع شاشات الهواتف.
- تصميم مناسب للمس.
- سحب وإفلات المكونات.
- توصيل الأسلاك باللمس.
- تكبير وتصغير لوحة الرسم.
- إمكانية التثبيت كتطبيق ويب تقدمي (PWA).

3. أجهزة الكمبيوتر (Desktop)

- دعم Windows.
- التوسع لدعم أنظمة الكمبيوتر الأخرى مستقبلاً.
- تطبيق سطح مكتب باستخدام Tauri.

حالة المشروع

المشروع حالياً في مرحلة التأسيس والتخطيط.

أول هدف تطويري هو بناء محاكي Classic Control.

سيركز الإصدار الأول على إنشاء الدوائر الكهربائية الأساسية وتوصيلها ومحاكاتها.

التقنيات المستخدمة والمقترحة

- React
- TypeScript
- SVG
- Tauri لتطبيقات الكمبيوتر
- Progressive Web App (PWA)
- Responsive UI لدعم الهاتف والويب
- Git
- GitHub

البنية البرمجية

يهدف المشروع إلى استخدام محرك محاكاة مشترك يعمل عبر جميع المنصات.

سيتم تطوير البرنامج ببنية وحدات مستقلة (Modular Architecture)، تسمح للمطورين بالمشاركة في تطوير أجزاء مختلفة من المشروع.

الوحدات المستهدفة:

- محرر الدوائر الكهربائية (Circuit Editor)
- مكتبة المكونات (Component Library)
- محرك المحاكاة (Simulation Core)
- أدوات التحليل الكهربائي (Electrical Analysis Tools)
- محرك PLC
- إدارة المشاريع وحفظها (Project Manager)

أنماط الاستخدام

وضع التعلم (Learning Mode)

مخصص للطلاب والفنيين.

- دروس تفاعلية.
- شرح المكونات الكهربائية.
- تمارين كهربائية عملية.
- عرض سلوك الدوائر.
- محاكاة الأعطال واستكشافها.

الوضع الهندسي (Engineering Mode)

مخصص للمهندسين والفنيين ذوي الخبرة.

- تصميم الدوائر الكهربائية.
- المحاكاة الكهربائية.
- تحليل الأنظمة.
- اختبار الأعطال.
- الحسابات الهندسية.
- التقارير الفنية.

تُعرض نتائج المحاكاة مع الافتراضات والقيود الفنية، ولا تُعتبر بديلاً عن التحقق الهندسي المعتمد للتركيبات الحقيقية.
